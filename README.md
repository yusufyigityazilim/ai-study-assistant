# AI Study Assistant

A web-based study assistant project designed to help students organize their learning materials.

## About the Project

AI Study Assistant aims to make studying easier by allowing students to work with PDF documents and generate useful study materials.

This project is currently under development.

## Current Features

- PDF file selection
- PDF file type validation
- Interactive user interface
- File selection status messages

## Technologies

- HTML5
- CSS3
- JavaScript
- Git & GitHub

## Planned Features

- PDF text extraction
- Automatic text summarization
- Multiple-choice quiz generation
- Flashcard generation
- User-friendly study dashboard

## Project Structure

ai-study-assistant/

## Getting Started

1. Clone this repository.
2. Open the project folder in Visual Studio Code.
3. Run `index.html` using Live Server.
